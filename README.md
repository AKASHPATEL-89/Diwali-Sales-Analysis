# 📊 Diwali Sales Analysis Dashboard

## 📌 Project Overview

This project is an end-to-end **Diwali Sales Analysis Dashboard** developed using **Python for data cleaning and exploratory data analysis** and **Microsoft Power BI for interactive data visualization**.

The project focuses on analyzing customer purchasing behavior during the Diwali season, including customer demographics, sales amount, orders, product categories, occupation, gender, age groups, and state-wise analysis.

---

## 🎯 Project Objectives

* Clean and prepare the raw Diwali sales dataset.
* Perform exploratory data analysis using Python.
* Analyze customer demographics and purchasing behavior.
* Identify high-performing product categories.
* Analyze sales and orders across different states.
* Compare purchasing behavior by gender and age group.
* Analyze customer spending based on occupation.
* Build an interactive Power BI dashboard for business insights.

# 🧹 Data Cleaning

Data cleaning and preprocessing were performed using **Python and Pandas**.

The following steps were performed:

* Loaded the CSV dataset using Pandas.
* Checked for missing values.
* Removed unnecessary columns.
* Removed null values.
* Corrected data types.
* Converted the `Amount` column into the appropriate numeric format.
* Prepared the dataset for analysis and visualization.
